---
title: "Quickstart"
description: "Retrieve your first transcript with a caption-only request."
---

<Steps>
  <Step title="Create an API key">
    Sign in to [the dashboard](https://transcriptfetch.com/app), open API keys,
    and create a key. Copy it when it is shown and keep it server-side.

    ```bash
    export TRANSCRIPTFETCH_API_KEY="YOUR_API_KEY"
    ```
  </Step>

  <Step title="Request a transcript">
    This example uses `mode: "captions"` to retrieve an existing caption track
    without starting AI transcription.

    ```bash
    curl --request POST \
      'https://transcriptfetch.com/api/v2/transcripts/video' \
      --header "Authorization: Bearer $TRANSCRIPTFETCH_API_KEY" \
      --header 'Content-Type: application/json' \
      --data '{"video":"https://youtu.be/aircAruvnKk","mode":"captions","timestamps":true}'
    ```
  </Step>

  <Step title="Read the result">
    On success, read timestamped cues from `data.segments`. Set
    `timestamps: false` to request `data.text` instead.

    If the request fails, inspect `error.code` and retain `request_id` for
    troubleshooting. A video without an available caption track cannot succeed
    in captions-only mode.
  </Step>
</Steps>

## Use AI transcription when needed

The default `mode: "auto"` tries captions first and can transcribe audio when
captions are missing. `mode: "audio"` requests audio transcription directly.
A request can return `202` with a `job_id` and `poll_url` instead of finished
text. See [Transcription and jobs](/guides/transcription) before enabling this
path. Caption retrieval and audio transcription have different billing rules.
