## API reference

Open the **API reference** tab for request parameters, response schemas, and code
examples generated from the public v2 OpenAPI specification.

<Info>
The trial's API playground displays code examples only. It does not execute
requests. Run examples in your own terminal and keep API keys server-side.
</Info>
